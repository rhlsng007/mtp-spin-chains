# Results notes (T8.3)

One note per phase, written for the Results chapter. Each note records

1. **Status**: the commits and tags that produced the results, tests and checks;
2. **Parameters**: what was run (sizes, grids, depths, strengths, shots, seeds);
3. **Key observations**: the results, with numbers;
4. **Failures and surprises**: what went wrong or was unexpected, and how it was resolved;
5. **Thesis figures**: the figures that show the results, each regenerated by one command.

Every number in these notes comes from a saved result: the phase summaries
(`results/phaseN/phaseN_summary.txt`), the phase report data
(`results/phaseN/phaseN_report_data.json`), the Phase 7 tables
(`results/phase7/tables/*.csv`) or the thesis-figure manifest
(`figures/thesis/MANIFEST.md`, 146 checks, all passing). Where a value is quoted
in the manifest, the figure script recomputes it from the data at every run.

Conventions used throughout: open TFIM chains

$$
H = -J\sum_{i=1}^{N-1} Z_i Z_{i+1} - h\sum_{i=1}^{N} X_i, \qquad J = 1, \qquad h_c = 1,
$$

relative energy error and noise error budget

$$
\epsilon = \frac{E - E_0}{|E_0|}, \qquad \lambda = p\,(n_{1q} + f\,n_{2q}),
$$

with f = 1 in Phase 4 and f = 10 for the hardware-like model of Phases 5 to 7
(f = 2 for amplitude damping and dephasing in Phase 5). The error budget is the
expected number of gate errors per circuit.
